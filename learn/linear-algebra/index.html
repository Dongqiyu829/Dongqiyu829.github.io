贯穿全课的矩阵

它一开始只是方程组的系数表；随后变成“把向量 x 送到 Ax”的机器。以后我们会发现：它可逆，行列式为 3，迹为 4；方向 (1,1) 被放大 3 倍，方向 (1,−1) 保持原长度。这一个例子会把计算、几何和抽象概念串在一起。
