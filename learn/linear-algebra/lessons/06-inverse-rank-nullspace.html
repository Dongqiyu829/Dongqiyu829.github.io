01 · Information Lost or Preserved?

可逆就是能把每个输出唯一倒回输入

对贯穿矩阵 A，输入 (2,1) 给输出 (5,4)。若每个平面中的输出都恰好来自一个输入，就有“倒回去”的规则，记作逆矩阵 A⁻¹。它满足 A⁻¹A=AA⁻¹=I：先变再倒回、先倒回再变，都会回到原输入。这里的逆是方阵的双侧逆，不是把四格数字分别取倒数。

把 A 的两列看成输出方向 (2,1) 与 (1,2)。它们不在同一条直线上，能拼出平面任意输出，并且配方唯一。若两列被调成同一方向，某些输入差异会在输出中消失。

本课 B 取 1122，是 Lesson 02 的压扁例子，和 Lesson 04 的剪切矩阵 B 不同；贯穿各课保持不变的是 A。

实验：把两列压到同一条线

将当前矩阵记作 M。上图是输入平面，下图是输出平面。青色 u 固定，珊瑚色 v 随 t 移动；比较下图 Mu 与 Mv 是否重合。下图金色、紫色箭头是矩阵两列，可拖动端点。所有数值都有文字读数。

先记住图中的两个词：秩数的是“输出最多能独立变化几个方向”；零空间收集“会被送到零的输入”。下一节再给完整定义。零矩阵就是四格全为 0 的矩阵。

  1. 选 B，把 t 从 0 调到 1。输入从 u=(1,0) 变为 v=(2,−1)，但两个输出仍是 (1,2)。继续移动 t，看“不同输入得到同一输出”。
  2. B 的输入图中，青色虚线过原点，是零空间；紫色虚线过 u，是输出同为 Mu 的输入集合。它们平行，位置不同：零空间是“差多少仍不改变输出”的方向。
  3. 切回 A，取 t≠0：这次输入改变，输出也跟着改变。最后试零矩阵：所有输入都变成零，整个输入平面都是零空间。

“压扁”矩阵 B = 1122 把 (x,y) 送到 (x+y,2x+2y)。例如 (3,0) 和 (2,1) 都送到 (3,6)，无法根据输出区分这两个输入。反之 A 的两个输出方向独立，不会这样撞在一起。

02 · Rank and Null Space

输出方向有几个？哪些输入变成零？

矩阵所有可能输出组成的集合叫列空间，因为每个输出都是列向量的线性组合。秩（rank）是这些输出中最多可选出的线性无关向量数，也就是列空间的维数；在二维例子中，只可能是 0、1、2。零空间（null space）是所有满足 Mx=0 的输入集合。注意：列空间位于输出端，零空间位于输入端；两者都是集合，秩才是一个数字。

三个可见的情形

  • A 的两列不平行：秩 2，列空间是整个平面；零空间只有零向量。
  • B 的两列相同：秩 1，列空间是沿 (1,2) 的直线；因为 B(1,−1)=(0,0)，零空间是所有 t(1,−1)。
  • 零矩阵：秩 0，列空间只有零向量；每个输入都在零空间。

对于 2×2 矩阵，秩 2 ⇔ 可逆 ⇔ 零空间只有零向量。理由是：若两个不同输入有相同输出，它们的差会被送到零；反过来，若有非零输入被送到零，把它加到任何输入上，就得到同一输出的另一份输入。高维与非方阵情况要再细分。

03 · Row Reduction

行消元：改变方程写法，不改变解

想倒推 A 的输出 (5,4)，就是解 2x+y=5、x+2y=4。增广矩阵把每条方程的系数和等号右边数字排在同一行，竖线只是分隔符。合法的三种初等行变换是：交换两行；某行乘非零数；某行加上另一行的倍数。它们保持方程组的解集，但通常会改变矩阵作为几何变换的样子，这两个意思不要混淆。

轮到你选择行操作：不只有“下一步”

输入是当前增广矩阵和你选择的操作，输出是改写后的两条限制。R₁、R₂ 表示第一、第二条方程。先想清楚要消掉哪一格，再选操作；观察哪些系数改变、共同解是否保持。可以从常用操作开始，再展开完整控制。需要时才点提示；参考完整路径单独折叠。挑战模式还会要求你先预测新右端，再执行一步。允许撤销、重置和随时自由探索。

工作台支持小数及 −1/3 这样的分数输入，但不是符号代数系统：内部用浮点数，表格约显示三位小数。它会拒绝超出数值精度范围、或无法可靠保持解集类型的步骤，并保留原状态；这是演示限制，不表示精确数学中的该操作不合法。纸上计算时可保留分数。

即时自测：行变换

把第二行 R₂ 改成 R₂−2R₁ 时，竖线右边的数要不要一起变？

同一套方法也能解三元方程

未知数增加时，每行多一格系数，规则仍是整行一起操作。试解 x+y+z=6、2x+y−z=1、x−y+2z=5。你可以先在纸上尝试，下面只在展开后显示一条路径。

展开三元消元与回代（不需要三维图）
  1. R₂←R₂−2R₁，得到 −y−3z=−11。
  2. R₃←R₃−R₁，得到 −2y+z=−1。
  3. 用新第二行：R₃←R₃−2R₂，得到 7z=21，因此 z=3。
  4. 回到 −y−3z=−11，得 y=2；再回第一式得 x=1。
  5. 验原式：1+2+3=6；2+2−3=1；1−2+6=5。三个非零主元表示三条独立限制，三个未知数恰有唯一解。

每步可逆的行操作保持解集，这是一般理由；图中观察到交点不动只是二维佐证。工作台目前只画两元情形，三元示例在纸上计算。

04 · Inverse in Practice

同一台机器，能否用于所有输出倒推？

逆矩阵的数字从哪里来？把目标从 (5,4) 改成任意 (p,q)，解 2x+y=p、x+2y=q。第一式乘 2 减第二式，得 3x=2p−q；第二式乘 2 减第一式，得 3y=2q−p。所以：

x = (2p−q)/3， y = (−p+2q)/3xy = 2/3−1/3−1/32/3pq

对 A，我们可以写出固定的逆规则：A⁻¹ = 2/3−1/3−1/32/3。验证时，不必猜：第一行第一列是 2·(2/3)+1·(−1/3)=1，第一行第二列是 2·(−1/3)+1·(2/3)=0；其余两格分别为 0、1，于是 AA⁻¹=I。再乘输出 54，得到输入 21。

对 B，输出 (3,6) 有无穷多输入；输出 (3,5) 则根本没有输入，因为 B 的输出第二分量必须是第一分量的两倍。于是“不可逆”不只是算不出一个公式，而是输出无法一一对应输入。

亲手倒推一次：A 的输出是 (7,8)

纸笔训练：同一个矩阵，两种结局

对 B = 1122，分别以列向量 36 与 35 为目标输出，求可能的输入。说清每个方程组有多少解，并写出理由。

第一组给 x+y=3 和 2x+2y=6；第二条只是第一条的 2 倍，因此有无穷多解：(x,y)=(t,3−t)，t 为任意实数。第二组给 x+y=3 和 2x+2y=5；第一条乘 2 应得到 6，却要求得到 5，矛盾，所以无解。几何上，两者对应目标是否落在 B 的输出直线上。

Beyond the Course · 进阶视角（不参与自测）

秩—零度定理

对从 ℝⁿ 出发的矩阵，秩 + 零空间的维数 = n。在本课二维例子中，A 是 2+0=2，B 是 1+1=2，零矩阵是 0+2=2。它量化了“保留下来的输出方向”与“丢失的输入方向”。

如何一次求出逆矩阵？

把方阵 M 与 I 并排写成 [M | I]，对整张表做相同的行变换。若左半能化成 I，右半就是 M⁻¹；若化不成 I，就没有逆。这个办法本质是在同时求 M 对 e₁、e₂ 等每个基本输出的倒推输入。Lesson 07 会从面积角度再给二维可逆性一个数值信号。
