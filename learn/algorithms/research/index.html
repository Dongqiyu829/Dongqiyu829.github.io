候选研究计划，不冒充已完成解读

  • Set Cover：具体覆盖问题 → 贪心近似 → 近似困难性；建议在贪心、NP 完全性后。
  • Subset Sum：小集合的两半枚举与 Meet-in-the-Middle；建议在分治、DP 后，再讨论精确指数改进。
  • Maximum Flow / Matching：先建立流与匹配的正确性工具，再选可核验的现代突破。
  • ETH / SETH 与 Fine-Grained Reductions：明确参数增长和归约方向，避免把条件下界当无条件定理。
