Reference · Asymptotic bounds

先数工作，再找两侧界

这张卡用于查阅；初学请先走完第二课的具体例子。

一条完整的分析链

  1. 约定：n 表示什么？一次 work 做什么、花多少代价？
  2. 计数：固定一轮，写出次数；对所有轮求和得到 W(n)。
  3. 夹住：找与 n 无关的正常数 c₁、c₂ 和门槛 n₀，证明对所有 n≥n₀ 都有 c₁f(n)≤W(n)≤c₂f(n)。
  4. 回到整段程序：计入循环控制等开销，再给运行时间 T(n) 的结论。

三个符号只是在说界

以下都要求 W 最终非负、f 最终为正；常数必须固定，不随 n 改变。

O(f(n))：存在 c>0、n₀，对所有 n≥n₀，W(n)≤cf(n)。这是上界。

Ω(f(n))：存在 c>0、n₀，对所有 n≥n₀，W(n)≥cf(n)。这是下界。

Θ(f(n))：上下两侧都成立，允许两侧使用不同正常数。这是同阶（tight bound）。

W(n)=Θ(f(n)) 是约定写法，并不是说 W 与 f 数值相等。O、Ω 本身也不等于“最坏／最好情况”；先选定要分析的工作量函数，再谈它的界。

第二课的证明，压成三行

W(n) = (n−1)+⋯+1+0 = n(n−1)/2
n≥2 时：¼n² ≤ W(n) ≤ ½n²
所以 W(n)=Θ(n²)

单位代价模型下，本例还有 aW(n)≤T(n)≤b(W(n)+n+1)，其中 a,b>0 固定，因此 T(n)=Θ(n²)。

允许自身配对时：W(n)=n(n+1)/2；n≥1 时，½n²≤W(n)≤n²，仍为 Θ(n²)。

复习时问自己

“我给出的是上界，还是已经找到了匹配下界？”只知道 W(n)≤n² 不够推出 Θ(n²)：W(n)=1 就是反例。有限样例可以检查计数，但不能证明对所有充分大的 n 都成立。
