COMP3711H Prep · Curriculum

从会写代码到会设计算法

路线不是固定日历。每课约 20–35 分钟；互动回答会决定下一次继续、补洞，还是提高难度。

为什么这样排

HKUST 官方课程目录定义目标边界；历届 COMP3711H 资料提供基础顺序、C++ 实现和本校题型；UMD CMSC451 用于深化图算法、设计范式、网络流、NP 完全性与近似算法。路线因此采用“短基础校准 → 设计范式主线 → honors 扩展”。

Phase A · 证明与分析的语言

  1. 二分搜索：为什么这半边可以丢？；先找 lower_bound 的边界，正式证明与 upper_bound 迁移可选展开。
  2. 数清工作量，再写 Θ(n²)：一个例子讲透双侧界；倍增计数等技巧按需要另开短课。
  3. 递推式上：从递归树看 Merge Sort
  4. 递推式下：Master theorem 的适用边界

Phase B · 分治、选择与数据结构

  1. Counting inversions：把跨区间贡献塞进 merge
  2. Randomized Quickselect：期望时间从哪里来
  3. Heap + priority queue：数据结构怎样改变算法代价
  4. Union–Find 与 amortized analysis（上/下）

Phase C · 三大设计范式

  1. Greedy exchange argument：interval scheduling
  2. 贪心何时会错：局部选择与反例生成
  3. DP 上：状态是“足够的过去”
  4. DP 下：weighted interval scheduling
  5. 字符串 DP：LCS 与 edit distance

Phase D · 图与优化

  1. DFS：时间戳、不变量与 topological order
  2. Strongly connected components（上/下）
  3. Shortest paths：Dijkstra 的贪心证明与负边界线
  4. MST：cut property 统一 Prim 与 Kruskal
  5. Network flow（上/下）：residual graph 到 max-flow min-cut

Phase E · Honors 视角

  1. Randomized algorithms：随机性放在哪里
  2. NP-completeness（上/下/应用）：验证、归约与证明方向
  3. Approximation：Vertex Cover 与 Set Cover 的保证
  4. Linear programming：建模语言与算法接口
  5. Capstone：一题限时完成四件套并复盘
