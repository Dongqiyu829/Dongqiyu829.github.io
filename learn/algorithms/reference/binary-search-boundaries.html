找分界线，守住两侧的事实

输入已从小到大排序，允许重复。先讲清任务与返回值，再选对应的更新规则。

lower_bound 的任务

返回第一个 a[i]≥x 的下标；若不存在，返回数组长度 n。例如 [1,2,2,4,7] 中，x=2 返回 1，x=3 返回 3，x=9 返回 5。返回 n 不表示可以访问 a[n]。

一套边界约定

  • 0≤lo≤hi≤n；lo 左边所有合法元素均<x，hi 起所有合法元素均≥x。
  • 尚待判断的元素在 [lo,hi)；答案下标则可能在闭区间 [lo,hi] 中，包括 hi。
  • 从 lo=0、hi=n 开始，循环条件 lo<hi；mid=lo+(hi−lo)//2。
  • a[mid]<x：lo=mid+1，连 mid 一起排除。
  • a[mid]≥x：hi=mid，mid 成为已知满足条件的右边界，仍可能作为最终答案。
  • lo=hi 时返回 lo；空数组直接返回 0。

正确性证明骨架

初始化：两侧已判断区域都为空，两条断言成立。

保持：有序性把关于 mid 的判断推广到它的一整侧；按上述更新，两条断言仍成立。

终止：lo≤mid<hi，每次使非负整数 hi−lo 严格减小。结束时 lo=hi，左边全<x，右边从 lo 起全≥x，得到第一个满足条件的位置；lo=n 则不存在。

比较次数：宽度每轮至多减半。对 n≥1，最坏情况比较次数为 ⌊log₂n⌋+1；这可由每次走 hi=mid 的分支达到。对 n≥2，最坏时间 Θ(log n)，额外空间 Θ(1)。n=0 时不作元素比较，函数为常数开销。

完整实现：C++

#include <vector>
using namespace std;

int lowerBound(const vector<int>& a, int x) {
    int lo = 0, hi = static_cast<int>(a.size());
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] < x) lo = mid + 1;
        else hi = mid;
    }
    return lo;
}

这里用 int 表示下标，假定数组长度可以由 int 表示。const vector<int>& 表示引用传入数组、函数不修改它；static_cast<int> 是把长度转成这里使用的下标类型。

完整实现：Python

def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo

理解后再迁移到 upper_bound

目标改为第一个 a[i]>x，则相等也应放在左侧。把分支条件改为 a[mid]≤x 时令 lo=mid+1，否则 hi=mid。对应不变量是“lo 左边都≤x，hi 起都>x”；其他边界约定不变。

不要混用其他二分模板的初始化、循环条件或 ±1 规则；从你选择的不变量推导更新。
