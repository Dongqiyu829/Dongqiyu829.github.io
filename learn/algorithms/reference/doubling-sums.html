Reference · Geometric sums

把实际各轮相加

适用程序：i 从 1 开始，每轮翻倍；只要 i≤n 就执行这一轮，且这一轮恰好做 i 次常数时间工作。

计数与边界

n=0：W=0。n≥1：令 M 是不超过 n 的最大 2 的幂，则 M≤n<2M。

W(n)=1+2+4+⋯+M=2M−1
n/2 < M ≤ W(n) < 2M ≤ 2n
所以 W(n)=Θ(n)

若 n 本身是 2 的幂，才可直接写 W(n)=2n−1。例如 W(8)=15，但 W(10)仍然是15，不是19。

外层轮数为 ⌊log₂n⌋+1（n≥1）。轮数乘最大一轮能推出 O(n log n)，但要得到紧确界，应计算实际的和。

为什么能用这个和分析运行时间？

work 每次花正常数时间。内层循环控制开销与工作次数加外层轮数成正比，而每轮至少执行一次 work。因此 n≥1 时，存在固定 a,b>0，使 aW(n)≤T(n)≤b(W(n)+1)，从而 T(n)=Θ(n)。n=0 时函数仍有常数控制开销。

计数实现：C++

n 是非负 int；倍增变量和计数用 long long。测试的 n 都很小，方便直接观察每次调用。

#include <iostream>
using namespace std;

long long countWork(int n) {
    long long count = 0;
    for (long long i = 1; i <= n; i *= 2)
        for (long long j = 0; j < i; ++j)
            ++count;
    return count;
}

int main() {
    cout << countWork(8) << '\n';  // 15
    cout << countWork(10) << '\n'; // 15
}

计数实现：Python

def count_work(n):
    count = 0
    i = 1
    while i <= n:
        for j in range(i):
            count += 1
        i *= 2
    return count

print(count_work(8))   # 15
print(count_work(10))  # 15

把 ≤ 改成 <

n=8 时总次数改为7；n=10时仍为15。对 n≥2，最后一轮 M 满足 M<n≤2M，仍有 W=2M−1，并且 n/2≤W<2n，所以紧确界仍为Θ(n)。n=0、1时新循环都执行0次。
