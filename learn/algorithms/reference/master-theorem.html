Reference · Master Theorem

先列各层，再用定理

三本账

n=bᵏ，固定整数 a≥1、b≥2，T(1)=Θ(1)，f≥0：单节点自身 f(n/bᵈ)，整层 aᵈf(n/bᵈ)，整树为所有内部层加 Θ(nᵖ) 叶子，p=log_b a。不要重复计入子递归。

经典三情形

  • f=O(nᵖ⁻ᵋ)，固定 ε>0 → Θ(nᵖ)。
  • f=Θ(nᵖ) → Θ(nᵖlog n)。
  • f=Ω(nᵖ⁺ᵋ)，且 a f(n/b)≤c f(n)，固定 0<c<1 → Θ(f(n))。

以上是幂规模上的版本；推广到任意整数及取整须明确额外条件。n log n 不比 n 多一个多项式因子；T(n−1) 不属于固定比例缩小。

三个自编模型（含叶子成本 1）

2T(n/2)+n：每层 n，总 n(log₂n+1)。2T(n/2)+n²：各层 n²/2ᵈ，总 2n²−n。2T(n/2)+1：各层 2ᵈ，总 2n−1。

迁移 4T(n/2)+n：叶子 n²，内部层 n2ᵈ，总 2n²−n。界必须上下匹配。2T(n/2)+n log₂n：内部层 n(k−d)，求和 Θ(n log²n)，需要树或扩展定理。
