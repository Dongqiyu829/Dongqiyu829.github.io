算法设计题四件套

一页检查表：让答案既能实现，也能被证明和评分。它来自历届 COMP3711H 明确给出的答题结构。

1 · 核心想法

先用 2–4 句话说清“利用了什么结构”。不要把伪代码翻译成中文；要指出为什么问题规模变小、为什么局部选择安全，或状态为何足够。

自检：删掉代码后，读者还能复述你的策略吗？

2 · 精确算法

给出足以无歧义实现的 pseudocode 或 plain-language algorithm。写明输入、输出、初始化、更新、终止条件和边界情况。

自检：另一个人能只靠这段描述写出同一个算法吗？

3 · Tight complexity

先定义输入规模，再数主导操作。若声称 Θ 而非 O，需要同时说明上界和匹配的下界；递归算法要先写 recurrence。

输入规模 → 每层代价 × 层数，或 recurrence → bound

4 · Correctness proof

证明必须对应算法结构，而不是复述“显然正确”。

算法类型常用证明骨架
循环初始化 → 保持 → 终止（loop invariant）
递归 / DP归纳假设 → 子问题覆盖 → 合并正确
贪心exchange argument / stays-ahead / cut property
图搜索可达性不变量 + 首次发现/最终确定时刻
