## 修改与教学目的

- `assets/recursion-tree.js`、`.css`：同一组件提供 Split / Merge 两阶段。Split 标记原始子数组、子问题规模和边界，已完成合并写入为 0；Merge 自底向上揭示左右有序返回、本节点自身 merge 写入及返回结果。等待中的节点不提前展示结果；顶部另给当前层返回示例，方便手机阅读。
- `lessons/0004-merge-sort-recursion-tree.html`：轻量阶段控件、n=6 非二次幂例子、静态 n=5 拆分/返回例子；明确阶段切换/重置行为与按层记账不等于执行顺序。补充折叠的峰值空间、栈深度、累计写入与稳定性说明，以及下一课前的口头诊断。
- `reference/merge-sort-tree.html`：同步峰值空间与累计工作的区别。当前复制数组实现的辅助空间为 Θ(n)，递归栈自身 Θ(log n)；前提与回收假设写明，不把教学图的快照缓存当作排序程序内存。
- `docs/LESSON05_PLAN.md`、路线和 `TEACH_SYNC.md`：第五课仅作规划。先检查 n=8 的节点/层/整树 4/8/24 及理由，再决定补练或比较等量、上层集中、下层集中的工作分布；最后才引出定理和适用条件。没有第五课 HTML，也没有新增 published 课时。
- `scripts/recursion-tree-test.cjs`（新增）、`test-site.cjs`、`test-merge.cjs`：扩充节点返回模型与实际浏览器阶段验收。`course-manifest.json` 更新发布号，所有旧 HTML 仅机械同步版本及元数据；共享 Compiler Lab、完成存储、代码 JSON 和前三课正文不改。

主线仍为 20–25 分钟、单一目标“按递归树证明总工作量”；空间与稳定性均可选。独立迁移题、提示/参考解、手动复制回答和自由访问保留；发布、自动测试和完成标记不代表学习者已掌握。
