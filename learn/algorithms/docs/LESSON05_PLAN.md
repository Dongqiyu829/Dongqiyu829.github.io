## 一项核心成果

从每层工作量的变化判断总和主要来自哪里，并能核验所用 Master Theorem 版本的适用条件；公式作为刚完成推导的压缩记录。

先统一 a=2、b=2、n=2^k、T(1)=Θ(1)，用三个自编工作模型，d=0,…,k−1：

| 递推与单节点自身工作 | 深度 d 整层工作 | 总量与来源 |
|---|---|---|
| T(n)=2T(n/2)+n | 2^d(n/2^d)=n | k 个等量层，另加叶子 Θ(n)，总 Θ(n log n) |
| T(n)=2T(n/2)+n² | 2^d(n/2^d)²=n²/2^d | 从根向下递减，几何和 Θ(n²)，上层集中 |
| T(n)=2T(n/2)+1 | 2^d | 向下翻倍，含 n 个常数叶子，总 Θ(n)，下层集中 |

教学步骤：先预测 n=8 的各层数 → 手算三串和 → 分辨叶子/自身工作 → 再引入 T(n)=aT(n/b)+f(n) 与 n^(log_b a)。这里的 a 是子问题数，b 是缩小比例，f 只计本节点自身工作。不要先抛三行公式让学生套用。

## 严谨性与边界

先使用经典三情形版本：固定整数 a≥1、常数 b>1、非负的 f、常数边界成本；先在 b 的幂上说明树。情形 1/3 要有多项式级差距 ε>0；情形 2 首轮仅讲 f=Θ(n^(log_b a))。情形 3 还需 a f(n/b)≤c f(n)，固定 c<1，充分大的 n 成立。一般整数、取整、渐进关系的额外假设要明确，不能把幂上的图直接宣称为任意 n 的完整证明。

边界挑战：T(n)=T(n−1)+n 不满足固定比例缩小；T(n)=2T(n/2)+n log n 不落入上述经典三情形的等量分支，不能把“比 n 大一点”当成多项式差距。后者仍可树求和为 Θ(n log²n)，或在未来明确引入扩展版本；不要说“任何 Master Theorem 都不能处理”。

独立迁移建议：T(n)=4T(n/2)+n，先写节点数、规模、每层自身工作与叶子贡献，再给匹配上下界、最后检查定理。参考结论 Θ(n²)，答案默认折叠；错误反馈指向漏算 4^d、把节点当整层、漏叶子、只证明上界等具体误区。
