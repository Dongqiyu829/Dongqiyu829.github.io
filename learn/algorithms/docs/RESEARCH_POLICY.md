# 算法前沿栏目维护规范

主线教授体系，专题展示研究如何发展。专题存放 research/，独立目录；不放入 course-manifest.lessons，不写完成键，没有解锁。assets/research-catalog.json 保存题名、署名、首次公布、稿件/修订日期、来源版本、状态、核查日、课程关系与追加式历史，静态页必须对应。

研究状态分开记录：预印本；发布方报告形式化；本站是否重建；外部独立审查进度；正式发表；确认、争议、反驳、撤回。核查日期不是确认日期。期刊发表不等于每条界都获形式化覆盖；形式化范围也不自动等于自然语言最强结论。

首次写作读取原始论文（PDF 不可读取时明确使用同目录源码）、范围文档、实际验证配置及外部原始报告。保留 commit 固定链接，同时给 main 最新入口。不依赖新闻标题或评论给研究升级状态。若有变量规模、编码长度、k 固定、随机/确定性或空间模型的差别，必须明确。

实质更新包括：新定理/界修订、明确的独立确认、带具体错误位置的关键反驳、撤回、正式审查报告。每次追加日期、旧陈述、变更、证据链接、受影响段落；保留旧版本。不要悄悄改旧结论。普通宣传、转发、仓库时间戳、有人参与审查均不构成确认。

持续跟踪优先：组合优化、SAT、近似、精确指数、网络流、匹配、Fine-Grained Complexity。先做小例子与一项可思考问题，再给前沿结果；其余候选只记录研究计划，避免一次堆成论文翻译库。

监测任务只做定时检索与报告；它不是网站的自动发布器。用户本轮确认 ChatGPT 监测为每周一执行，具体时刻未在本地核验，不臆填；上一轮本地每日 heartbeat 已暂停以避免双重监测，未创建新任务。未来改变频率后按真实配置更新文档。

例行检索无实质变化时保持安静。网站维护是单独工作：取得实质原始证据后，核对受影响陈述，再更新 catalog、专题与追加式记录、TEACH_SYNC，运行静态/链接与受影响浏览器测试后发布；发布前重新核对 GitHub HEAD 并保留并发修改。不能把检索失败当研究被反驳，也不能凭新闻转载或仓库更新时间升级状态。
