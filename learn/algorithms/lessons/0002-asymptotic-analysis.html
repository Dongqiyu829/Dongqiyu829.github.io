01 · 一个具体问题

把数组中每一对位置比较一次

数组有 n 个元素。我们想比较每一对不同位置，且 (i,j) 与 (j,i) 只算一对，因此只取 i < j。

// C++：n 是数组长度
for (int i = 0; i < n; ++i) {
    for (int j = i + 1; j < n; ++j) {
        work(a[i], a[j]);
    }
}

一个实际用途是统计逆序对：位置 i<j，但 a[i]>a[j]。朴素办法会检查每一对位置，再判断是否逆序。本课只数“检查一对”被执行多少次；更快的方法留到分治专题。

先约定：一次 work 只比较两个机器字范围内的整数，花常数时间。记 W(n) 为它被调用的次数。循环不提前退出，所以数组里的数值不影响这个次数。

先别写复杂度：当 n = 4 时，work 一共执行几次？

02 · 从手算到通式

固定一轮，再把所有轮加起来

当 i = 0 时，还有 n−1 个位置可配对；当 i = 1 时，还剩 n−2 个。一直到最后一轮，没有后面的位置可配对。

W(n) = (n−1) + (n−2) + ⋯ + 1 + 0

停一下：把这串数倒着写在下面，两行相加，每一列会是多少？

展开配对推导 
  W = (n−1) + (n−2) + … + 1     + 0
  W = 0     + 1     + … + (n−2) + (n−1)
------------------------------------------------
 2W = (n−1) + (n−1) + … + (n−1)   ← 共 n 列

所以 2W(n) = n(n−1)。这不是记住一个求和公式，而是把两份三角形拼成矩形。

W(n) = n(n−1) / 2

代回 n = 4，得到 4×3/2 = 6，和刚才的逐轮计数一致。

03 · 给增长方式起一个名字

为什么说它是“二次增长”？

n(n−1)/2 并不等于 n²。我们说它与 n² 同阶，意思是：从某个规模开始，它始终能被两个固定倍数的 n² 夹住。

先看上界。因为 n−1 ≤ n：

W(n) = n(n−1)/2 ≤ n²/2

再看下界。当 n ≥ 2 时，n−1 ≥ n/2，所以：

W(n) = n(n−1)/2 ≥ n(n/2)/2 = n²/4

把这两句话放在一起：

对所有 n ≥ 2：
¼ n² ≤ W(n) ≤ ½ n²
因此 W(n) = Θ(n²)

这就是 Θ（Theta）：上下两边都夹住了。这里的 ¼、½ 可以不同，但都必须是不随 n 改变的正常数。

现在再读正式定义

对最终非负的工作量函数 W 和最终为正的比较函数 f，若存在常数 c₁,c₂ > 0 与门槛 n₀，使所有 n ≥ n₀ 都满足

c₁ f(n) ≤ W(n) ≤ c₂ f(n)

就写 W(n) = Θ(f(n))。本例取 f(n)=n²、c₁=¼、c₂=½、n₀=2 即可。只试几个 n 不是证明；两个不等式对所有 n≥2 成立才是。

这与 MIT 6.006 关于双侧界的解释（第 1 页）一致。

如果只证明上面那一边，记作 W(n)=O(n²)；

只证明下面那一边，记作 W(n)=Ω(n²)。

今天先把“Θ 要两边”用熟，三个符号的辨析放在复习卡中。

假如只知道 W(n) ≤ n²，足够推出 Θ(n²) 吗？

我们数的是 work，为什么能说整段程序也是 Θ(n²)？

令 T(n) 为整段程序在单位代价模型下的基本操作总成本。每次 work 都花正的常数时间，因此 T(n) ≥ aW(n)，其中 a>0。

内层比较、递增等控制操作的次数至多是 W(n) 加上每轮外层的常数开销；外层只有 n 轮。因此存在固定常数 b>0，使 T(n) ≤ b(W(n)+n+1)。

当 n≥2 时，n 和常数项都可被 n² 的固定倍数盖住，于是 T(n) 的上下界也是 n² 的固定倍数：T(n)=Θ(n²)。数组数值不影响循环次数，本例不用另分最好与最坏输入。

写完后核对推导

每轮依次有 4、3、2、1 次，共 10 次。一般地，W(n)=n+(n−1)+⋯+1=n(n+1)/2。

对 n≥1，n ≤ n+1 ≤ 2n，所以 ½n² ≤ W(n) ≤ n²。取 c₁=½、c₂=1、n₀=1，得到 W(n)=Θ(n²)。
