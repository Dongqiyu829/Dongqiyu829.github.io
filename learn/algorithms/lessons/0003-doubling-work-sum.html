两层循环，
为什么只有 Θ(n)？

第二课把每轮次数加了起来。这次只改外层的走法：每次翻倍。我们看看，总工作量会怎样变。

约 15–20 分钟一个程序 · 一次求和先预测，再展开
今天只练一件事：写出每轮实际工作量，把它们相加，再给出匹配的上下界。你会用一个例子解释，为什么“轮数 × 最大一轮”有时只给了一个很松的上界。

先回忆第二课的一个动作

上一课，逐对比较的每轮工作量是 n−1,n−2,…,1,0。如果要证明总工作量为 Θ(n²)，除了上界，还差哪一边？先口头回答，再继续。

想过后核对

还需要一个固定正常数乘 n² 的下界。Θ 要上下两边；“至多这么多”只给了 O。若这一步还不熟，可以先回看第二课的两侧界。

01 · 只看这个程序

i 不再加 1，而是乘 2

输入 n 是非负整数。约定 work() 每次只做固定的常数时间工作。我们先数调用次数 W(n)，再看整个程序的时间。

// C++：i *= 2 表示把 i 翻倍
for (long long i = 1; i <= n; i *= 2) {
    for (long long j = 0; j < i; ++j) {
        work();
    }
}

外层的 i 依次取 1,2,4,8,…，超过 n 就停止。固定某一轮 i，内层的 j 从 0 到 i−1，因此这一轮恰好做 i 次 work。

先手算：当 n=8 时，work 总共执行几次？

02 · 先把四轮排开

1 + 2 + 4 + 8，不是 4 × 8

n=8 时，前面三轮合起来只有 1+2+4=7 次，还不到最后一轮的 8 次。虽然有四轮，总和却不到最后一轮的两倍。

每次加一轮，看看累积了多少工作

下一轮会做几次？先预测，再点按钮。柱长表示这一轮的调用次数，不表示运行秒数。

再取 n=16，会多出最后一轮的 16 次：

W(16) = 1+2+4+8+16 = 31

这种相邻项总按固定倍数变化的和，叫几何级数（geometric series）。今天只用“每项翻倍”这一种，不需要背通用公式。

03 · 用减法把规律推出来

让一串数和它的两倍错开

先看 n 是 2 的幂的情形，例如 1、2、4、8、16。此时最后一轮恰好做 n 次，记总和为 S：

 S = 1 + 2 + 4 + … + n
2S =     2 + 4 + … + n + 2n
--------------------------------
2S − S = 2n − 1

停一下：中间相同的项消掉后，为什么留下的是 2n−1？试着自己写一遍，再得到：

当 n 是 2 的幂时，W(n)=2n−1

对这些 n≥1，n ≤ 2n−1 < 2n。所以总工作量被 n 的两个固定倍数夹住。这就是线性增长的直觉。

但n=10 时最后一轮是 i=8，不会额外执行 i=10。此时 W(10)=15，不能套成 2×10−1=19。要对所有 n 证明 Θ(n)，还需补上这一点。

严谨补齐：n 不是 2 的幂时怎么办？

对任意整数 n≥1，把最后执行的 i 记成 M。它一定是某个 2 的幂，而且 M ≤ n < 2M：M 这一轮能执行，下一轮 2M 已超过 n。

同样用上面的减法，有 W(n)=1+2+⋯+M=2M−1。

下界：光是最后一轮就做 M 次，因此 W(n) ≥ M > n/2。

上界：W(n)=2M−1 < 2M ≤ 2n。

对所有 n≥1：½n < W(n) < 2n
所以 W(n)=Θ(n)

严格不等式也推出定义需要的非严格不等式；例如取 c₁=½、c₂=2、n₀=1 即可。n=0 时没有任何一轮，W(0)=0；渐进结论并不要求小输入也满足同一双侧界。

这样，我们不只验证了几个样例，还能对所有充分大的 n 给出上下界：W(n)=Θ(n)。

加上循环控制，整个程序也是 Θ(n) 吗？

是，在本课的单位代价模型下。每次 work 花正的常数时间，给出与 W(n) 成正比的时间下界。内层比较、递增的次数至多与 W(n) 加外层轮数成正比。

n≥1 时，每轮至少做一次 work，所以外层轮数也不超过 W(n)。因此存在固定 a,b>0，使 aW(n) ≤ T(n) ≤ b(W(n)+1)。于是 T(n)=Θ(n)。n=0 时函数仍有常数控制开销。C++ 示例假定 n 可由 int 表示，计数与倍增用 long long 避免这些输入下的溢出。

04 · 回头检查那个容易写出的上界

“轮数 × 最大一轮”错在哪里？

i 每轮翻倍，外层轮数是对数级；每轮内层至多做 n 次。所以相乘确实能给出 O(n log n) 上界。它把很多较小的轮次都按最大轮计费，因而不够紧。

已经证明 T(n)=Θ(n)，还能说它是 O(n log n) 吗？

记住今天的检查动作：轮与轮之间工作量不一样，就先写实际的和。不是所有两层循环都二次，也不是出现乘 2 就能直接决定总时间。

写完之后核对
n=8：i 只取 1、2、4，总共 7 次。n=10：i 仍取 1、2、4、8，总共 15 次，和改动前相同。
紧确界仍是 Θ(n)。对 n≥2，令最后一轮的 i 为 M，则 M<n≤2M，仍有 W(n)=2M−1。于是 W(n)≥M≥n/2，且 W(n)<2M<2n，得到匹配的线性双侧界。
n=1 时新循环一次也不执行；这只改变小输入，不影响从 n≥2 开始的渐进结论。修改代码后，8 个测试的期望值要相应改成 0、0、1、3、7、15、15、31。
