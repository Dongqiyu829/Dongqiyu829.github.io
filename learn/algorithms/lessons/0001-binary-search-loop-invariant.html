COMP3711H Prep · Lesson 01

二分搜索为何真的正确

今天不背 binary search 模板。我们只学一个可迁移的工具：用 loop invariant 推出每一次边界更新，并在结束时得到答案。

约 25 分钟 证明 + 手算 难度：基础校准
本课胜利条件：给定一个陌生的二分变体，你能先写“不变量”，再从不变量推出更新规则，而不是靠记忆猜 +1 与 -1。

任务：找第一个不小于 x 的位置

输入一个非降序数组 a[0..n) 和目标值 x。返回最小的下标 i 使 a[i] ≥ x；若不存在，返回 n。这就是常见的 lower_bound。

例：a = [1, 2, 2, 4, 7]，x = 2，答案是 1，不是随便某个值为 2 的位置。

唯一需要守住的画面

我们维护半开区间 [lo, hi) 作为“尚未判断”的区域。

已知 < xi < lo
未知区域lo ≤ i < hi
已知 ≥ xhi ≤ i < n

这句话就是不变量：

∀ 0 ≤ i < lo, a[i] < x　且　∀ hi ≤ i < n, a[i] ≥ x

答案始终藏在边界之间；我们只是不断把已经证明的部分从未知区移出去。

算法由不变量“长出来”

lower_bound(a, x):
    lo = 0
    hi = length(a)          // 注意：hi 可以等于 n

    while lo < hi:
        mid = lo + (hi - lo) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid

    return lo

若 a[mid] < x，由有序性可知 0..mid 都不是答案，所以令 lo = mid + 1。否则 mid 可能正是第一个满足条件的位置，不能丢掉它，因此令 hi = mid。

正确性证明：三步足够

1. 初始化

lo = 0, hi = n。在合法下标 0..n-1 中，左侧 i < 0 与右侧 i ≥ n 都是空集合，因此两条断言自动成立。

2. 保持

若 a[mid] < x，排序性证明直到 mid 都小于 x；否则从 mid 起都不小于 x。两种更新都不破坏不变量。

3. 终止

区间宽度严格变小，最终 lo = hi。未知区为空；左边全小于 x，右边从 lo 起全不小于 x，所以 lo 正是所求。

为什么是 Θ(log(n+1))

令第 t 轮前未知区宽度为 wₜ = hi - lo。每轮后至多保留一半：

wₜ₊₁ ≤ ⌈wₜ / 2⌉

从 w₀ = n 开始，经过 t 轮后宽度至多约为 n / 2ᵗ。宽度降到 1 后再做至多一轮便成为 0，因此迭代次数是 Θ(log(n+1))；当 n ≥ 2 时通常简写为 Θ(log n)。每轮只做常数次比较与赋值，额外空间为 Θ(1)。

最常见的坑：半开区间写法 [lo, hi) 与闭区间写法 [lo, hi] 都能正确，但它们的初始化、循环条件和更新规则是成套的。混用才会制造 off-by-one bug。
