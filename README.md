# Qiyu Dong — Personal Website

A lightweight static site for research/internship applications.

## Publish with GitHub Pages

1. On GitHub, create a new **public** repository named exactly `Dongqiyu829.github.io`.
2. Unzip this package. Upload **all files and folders inside `qiyu-personal-site/`** to the repository root (not the outer folder itself).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`; Save.
6. After GitHub finishes deployment, the site should be available at `https://Dongqiyu829.github.io/`.

## What to edit later

- `index.html`: text, links, project descriptions.
- `styles.css`: layout and visual styling.
- `assets/Qiyu_Dong_CV_AIMed.pdf`: replace this whenever the CV changes, keeping the same filename.
